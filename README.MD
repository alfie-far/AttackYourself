# AttackYourself

This repository was created for an AgentCore-based project.

## Initialize a new project

Run the following command from the repository directory:

```bash
agentcore create \
  --project-name AttackYourself \
  --no-agent
```

If you want to set it up from a fresh clone:

```bash
git clone https://github.com/alfie-far/AttackYourself.git
cd AttackYourself
agentcore create --project-name AttackYourself --no-agent
```
